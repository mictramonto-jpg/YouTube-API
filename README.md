# YouTube コメント抽出ツール

YouTube Data API v3 を使用して、YouTubeチャンネルの動画からコメントを抽出し、Excel ファイルに出力するデスクトップアプリケーションです。

## 機能

- YouTubeチャンネルの「動画」「ショート」「ライブ」タブから動画を取得
- 動画ごとのコメントを上位表示順に抽出
- コメントの高評価数によるフィルタリング
- コメントに含まれる文字列によるフィルタリング
- Excel ファイルへの自動出力
- リアルタイム進捗表示

## セットアップ

### 1. Python のインストール

Python 3.9 以上が必要です。  
https://www.python.org/downloads/ からダウンロードしてインストールしてください。

> **重要**: インストール時に「Add Python to PATH」にチェックを入れてください。

### 2. YouTube Data API Key の取得

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. 新しいプロジェクトを作成（または既存のプロジェクトを選択）
3. 左メニュー「APIとサービス」→「ライブラリ」をクリック
4. 「YouTube Data API v3」を検索して「有効にする」をクリック
5. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」をクリック
6. 生成されたAPIキーをコピーして保管

### 3. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

## 使い方

### 起動方法

**Windows:**
`run.bat` をダブルクリック、または:
```bash
python main.py
```

**Mac/Linux:**
```bash
./run.sh
```
または:
```bash
python3 main.py
```

### 操作手順

1. **YouTube Data API Key** を入力欄にペースト
2. **YouTubeチャンネルURL** を入力  
   対応URL形式:
   - チャンネルURL: `https://www.youtube.com/@チャンネル名/videos`
   - チャンネルURL: `https://www.youtube.com/@チャンネル名/shorts`
   - チャンネルURL: `https://www.youtube.com/@チャンネル名/streams`
   - 動画URL: `https://www.youtube.com/watch?v=VIDEO_ID`（チャンネルを自動特定）
3. **リサーチする動画数** を入力（デフォルト: 30）
4. **コメント高評価数の下限** を入力（0 = フィルタなし）
5. **コメントに含まれる文字** を入力（空欄 = フィルタなし）
6. **「稼働」ボタン** をクリック

### 出力

- 画面上のテーブルに結果がリアルタイム表示されます
- 完了時に Excel ファイルが自動保存されます（同じフォルダ内）
- 「Excelに保存」ボタンで任意の場所に保存することも可能です

### 出力項目（Excel A～G列）

| 列 | 項目 |
|----|------|
| A  | 動画URL |
| B  | 動画タイトル |
| C  | 動画投稿日 |
| D  | 投稿者名 |
| E  | コメント本文 |
| F  | コメント高評価数 |
| G  | コメント投稿日時 |

## 注意事項

- YouTube Data API には1日あたりのクォータ制限（デフォルト10,000ユニット）があります
- 「動画」タブの取得は効率的（1ユニット/リクエスト）ですが、「ショート」「ライブ」タブは検索APIを使用するためクォータ消費が多くなります
- コメントが無効化されている動画は自動的にスキップされます
- 処理中にエラーが発生しても、取得済みのデータは保持されます
